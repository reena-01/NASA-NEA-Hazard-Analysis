# NASA Near-Earth Asteroid Hazard Analysis

A Python-based data analysis and machine learning project for studying
Near-Earth Objects (NEOs) and identifying characteristics associated
with potentially hazardous asteroids.

## Project Goals

- Analyze Near-Earth Object data
- Clean and preprocess the dataset
- Perform exploratory data analysis
- Visualize asteroid characteristics
- Engineer useful features
- Build machine learning models
- Evaluate model performance
- Identify important hazard-related features

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Data Source

This project uses NASA's Near-Earth Object Web Service (NeoWs)
for Near-Earth Object data.

Source:
https://api.nasa.gov/

The raw data is downloaded programmatically using Python.
